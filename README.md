# FitLog
- A simple Fitness Log app powered By `Next.js`

---

  ## Short Description
  - Assignment-06, Batch-14 (Programming Hero). In this app user can experience a smooth UI/UX. add Workouts in Today's plan or save for later. Log their Workout.

---

  ## Technology used
    - Nextjs Framework
    - React
    - TypeScript
    - Tailwind css
    - Vite
    - React Toastify
    
---

  ## Features in this App
    1. Responsive Design (Desktop, Tablet and Mobile)

    2. Data fetch and loading from API.

    3. Interactive navigation with state management

    4. User Can Log their workout.

    5. Add Workouts for Today's Plan or Save for Later.
